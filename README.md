# Life Time (生命倒计时) ⏳

一款基于 **HarmonyOS** 开发的**生命倒计时**应用，帮助您直观地感知时间的流逝，并通过培养好习惯来"延长"生命。

---

> 📖 **快速上手**：先看 [`ARCHITECTURE.md`](ARCHITECTURE.md) 了解数据流和架构设计。

---

## 📱 应用概述

**Life Time** 通过设置出生日期和预期寿命，实时计算并展示剩余天数。您还可以自定义"好习惯"和"坏习惯"，每个习惯都会对寿命产生 +/- 天数的影响，让您直观地看到日常习惯对生命的量化影响。

> **Bundle Name**: `com.example.lifetime`
>
> **目标设备**: Phone
>
> **SDK 版本**: HarmonyOS 6.1.1 (API 24)

---

## ✨ 核心功能

### 🏠 主页 - 生命倒计时看板

- **剩余天数展示** — 基于出生日期和预期寿命实时计算剩余天数
- **进度可视化** — 用进度条直观展示生命已消耗与剩余比例
- **实时时钟** — 显示当前日期时间，持续更新
- **习惯偏移汇总** — 展示所有自定义习惯带来的总天数偏移（绿色 + / 红色 -）

### 🎯 习惯管理系统

- **✅ 好习惯** — 为每个好习惯设定增加的天数（如：运动 +5 天）
- **❌ 坏习惯** — 为每个坏习惯设定减少的天数（如：熬夜 -3 天）
- **可视化分类** — 好习惯用绿色标识，坏习惯用红色标识，一目了然
- **多习惯支持** — 支持添加多个自定义习惯，灵活管理

### ⚙️ 设置页面

- **🎂 出生日期** — 通过 DatePicker 组件选择出生日期（1900 年至今）
- **📅 预期寿命** — 自定义预期寿命（1-150 岁）
- **💾 自动保存** — 修改后通过 Preferences 自动持久化存储

### 🔄 数据备份

- 内置 **BackupExtensionAbility**，支持应用数据的备份与恢复

## 🚀 运行指南

### 环境要求

- **DevEco Studio** 5.0+ 版本
- **HarmonyOS SDK** 6.1.1 (API 24) 及以上
- 真机或模拟器（Phone 类型）

### 运行步骤

1. **克隆项目** 并导入 DevEco Studio
2. **同步依赖** — 等待 Gradle/Hvigor 同步完成
3. **配置签名** — 在 `build-profile.json5` 中配置签名信息（或使用自动签名）
4. **运行** — 点击 DevEco Studio 的 `运行` 按钮，选择 Phone 设备

## 🎨 界面设计

- **深色主题** — 以 `#0d0d1a` 深色背景为主，降低视觉疲劳
- **毛玻璃卡片** — 使用圆角卡片式布局，信息层次分明
- **色彩语义** — 好习惯使用绿色（`#44cc77`），坏习惯使用红色（`#ff4466`）
- **沉浸式体验** — 全屏布局，专注核心信息展示
